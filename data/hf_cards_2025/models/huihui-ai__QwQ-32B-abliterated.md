# huihui-ai/QwQ-32B-abliterated


This is an uncensored version of [Qwen/QwQ-32B](https://huggingface.co/Qwen/QwQ-32B) created with abliteration (see [remove-refusals-with-transformers](https://github.com/Sumandora/remove-refusals-with-transformers) to know more about it).  
This is a crude, proof-of-concept implementation to remove refusals from an LLM model without using TransformerLens.    


## Use with ollama

You can use [huihui_ai/qwq-abliterated](https://ollama.com/huihui_ai/qwq-abliterated) directly
```
ollama run huihui_ai/qwq-abliterated
```
All versions of ollama from Q2_K to fp16 are supported.
