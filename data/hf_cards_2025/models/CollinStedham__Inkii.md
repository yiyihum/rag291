# Model Card for Model ID

<!-- Provide a quick summary of what the model is/does. -->

Inkii is a proficient, very creative text generation model that excells in creating humanlike, original texts.

### Model Description

Inkii is an AI model that utilizes a "thought chain" reasoning method to create humanlike, creative, original texts. It is only capable of writing in the first person perspective. When we evaluated Inkii in our user testing, we found that on average Inkii wrote at a 11th-12th intellectual level and a 9th-10th grade emotional/"deepness" level. Inkii can be accessed on the Inkii Web Interface (https://cdn.botpress.cloud/webchat/v3.3/shareable.html?configUrl=https://files.bpcontent.cloud/2025/10/04/12/20251004125656-16I3MUYG.json)

## Uses

Inkii is intended to only be used for creative, first person text generation. As it has been trained with texts written in the first person, it is largly incapable of generating any other type of text. Inkii excells at writing poems, short stories, journals, and other creative texts.

### Direct Use

Type your prompt into the Inkii Web Interface (https://cdn.botpress.cloud/webchat/v3.3/shareable.html?configUrl=https://files.bpcontent.cloud/2025/10/04/12/20251004125656-16I3MUYG.json)

### Out-of-Scope Use

Using Inkii to cheat on school assignments, selling Inkii-generated content, and otherwise misusing Inkii in any way is a violation of Inkii's intended use policy. Inkii should only be used for the enjoyment of its users and the enjoyment of the broader commmunity. Inkii-generated content does NOT belong to the user, but the user can share the content according to the Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0
) license. This license does NOT apply to the model itself.


## Bias, Risks, and Limitations

Inkii, during testing, has shown a proclivity to unrealistically amplify "hardships" (such as losing a family member, living alone) in its writing. This does not pose any threat and is not a large problem, but it can cause Inkii's generations to sound insensitive and fake. This is a problem that may be solved in the future.

### Recommendations

When writing an Inkii prompt, include the word "realistic" in some form. For example, the original prompt of "write a poem about family loss" could be revised to "write a realistic poem about family loss". My tests show that Inkii's writing becomes much more sensitive if these changes are made.

## Training Details
Inkii was based on several existing LLM models as well as my own data. The models Inkii was trained on are listed here: GPT-5, GPT-5_nano, DeepSeek R1, Gemini Flash 2.0, Gemini Flash 2.5, Gemini 2.5 Pro, and GPT-4o. The additional data Inkii was trained on consisted of my own written text and open domain first-person texts.
