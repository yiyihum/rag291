### Reproduction steps
<details>

  <summary>Spoiler warning</summary>

  1. Retokenize `ReadyArt/Forgotten-Safeword-12B-v4.0` using [mergekit-tokensurgeon](https://github.com/arcee-ai/mergekit/blob/main/docs/tokensurgeon.md)
  ```bash
  mergekit-tokensurgeon "ReadyArt/Forgotten-Safeword-12B-v4.0" "Epiculous/Violet_Twilight-v0.2" ./retokenized_SA --approximation-method omp --k 512 --magikarp
  ```
  Note: After initial research I found that Forgotten Abomination might had some undesired tokens in previous version, that's why I cranked omp --k to eleven and added magikarp to filter out any undesired tokens. 

  2. Retokenize `allura-org/Bigger-Body-12b` using [mergekit-tokensurgeon](https://github.com/arcee-ai/mergekit/blob/main/docs/tokensurgeon.md)
  ```bash
  mergekit-tokensurgeon "allura-org/Bigger-Body-12b" "LatitudeGames/Wayfarer-12B" ./retokenized_BB --approximation-method omp --k 512
  ```

  3. Merge models using mergekit [mergekit-multi](https://github.com/arcee-ai/mergekit/blob/main/docs/multimerge.md)

  ```yml
    name: rp_blend
    merge_method: nuslerp
    models:
      - model: ./retokenized_SA
        parameters: 
          weight: 0.6
      - model: Epiculous/Violet_Twilight-v0.2
        parameters:  
          weight: 0.4
    ---
    name: danger_blend
    merge_method: nuslerp
    models:
      - model: LatitudeGames/Wayfarer-12B
        parameters:  
          weight: 0.8
      - model: ./retokenized_BB
        parameters: 
          weight: 0.2
    ---
    merge_method: passthrough
    slices:
    - sources:  # Base Model
      - model: Retreatcost/KansenSakura-Zero-RP-12b
        layer_range: [0, 22]
    
    - sources: # New RP blend
      - model: rp_blend
        layer_range: [22, 29]
    
    - sources:  # Shrinked by 1 layer
      - model: danger_blend
        layer_range: [29, 34]
    
    - sources:  # Extended by by 1 layer
      - model: LatitudeGames/Muse-12B
        layer_range: [34, 39]
    
    - sources:
      - model: Retreatcost/KansenSakura-Zero-RP-12b
        layer_range: [39, 40]
    dtype: bfloat16
  ```
  ```bash
  mergekit-multi sakuramerge_v2.yml --intermediate-dir ./intermediates --out-path ./KansenSakura-Eclipse-RP-12
  ```

  3. Optional - create Q8_0 GGUF using llama.cpp
  - use convert_hf_to_gguf.py script from llama.cpp (here's [source](https://github.com/ggml-org/llama.cpp/blob/master/convert_hf_to_gguf.py))
  ```bash
  python convert_hf_to_gguf.py ~/projects/KansenSakura-Eclipse-RP-12 --outtype q8_0
  ```
</details>
