# StarCoder-Python-Qwen-Instruct

## Dataset Description

This dataset contains Python code samples paired with synthetically generated natural language instructions. It is designed for supervised fine-tuning of language models for code generation tasks. The dataset is derived from the Python subset of the `bigcode/starcoderdata` corpus, and the instructional text for each code sample was generated using the **Qwen/Qwen3-Coder-30B-A3B-Instruct-FP8** model.

## Creation Methodology

The construction of this dataset involved a two-stage process:

1.  **Base Data Curation**: Python source code files were selected from the StarCoder dataset. The data was partitioned based on Python version, as indicated in the metadata of each sample.

2.  **Instruction Generation**: Each code snippet was provided as context to the `Qwen/Qwen3-Coder-30B-A3B-Instruct-FP8` model. The model was prompted to generate a corresponding instruction that would elicit the given code as a response. This process yields a collection of instruction-code pairs suitable for instruction fine-tuning.

## Data Filtering and Preprocessing

This dataset has been specifically filtered and preprocessed for fine-tuning models with a limited context window, such as the **OLMo-2** series, which has a context length of 4096 tokens.

To ensure that samples fit within this limit during training, the following filtering step was applied:
*   The total token count of each `(instruction, text)` pair was calculated.
*   Any sample exceeding a length of **3796 tokens** was removed.

This threshold was chosen to leave a safety margin of 300 tokens, which accommodates the inclusion of special tokens, instruction formatting, and other template-specific additions during the fine-tuning process.

## Data Structure and Fields

The data is provided in the JSON Lines (`.jsonl`) format, where each line is a distinct JSON object.

### Data Fields

Each JSON object contains the following fields:

*   `instruction` (string): A synthetically generated natural language instruction.
*   `text` (string): The corresponding Python code snippet from the StarCoder dataset.
*   `id` (string): A unique identifier for the data entry.
*   `metadata` (object): A nested object containing metadata from the original source.
    *   `extension` (string): The file extension, indicating the Python version (`python2` or `python3`).
    *   `max_stars_count` (string): GitHub stars of the source repository.
    *   `max_stars_repo_name` (string): Name of the source repository.
    *   `max_stars_repo_path` (string): File path within the source repository.
    *   `provenance` (string): The original source file within The Stack dataset.
*   `added` (string): Timestamp for when the entry was added.
*   `created` (string): Timestamp for when the entry was created.
*   `source` (string): The original dataset source (e.g., "starcoder").
