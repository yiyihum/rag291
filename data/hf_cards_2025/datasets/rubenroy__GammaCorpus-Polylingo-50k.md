# GammaCorpus Polylingo 50k

## What is it?

The **GammaCorpus Polylingo 50k** dataset consists of 50,000 structured, unfiltered, single-turn conversations, where each interaction includes:
- **Input**: A user prompt or question.
- **Output**: A response generated by an AI assistant.
- **Language**: The language used in the interaction.

This dataset is designed to help in the training and evaluation of conversational AI models for linguistic purposes. This dataset can be especially helpful if you need a large collection of a diverse human generated prompts and the corresponding responses by SOTA models.

## Dataset Summary

- **Number of Rows**: 50,000
- **Format**: JSONL
- **Languages**: 20 Languages (130 total for smaller languages)
- **Data Type**: User and AI-generated content
- **Potential Content**: May contain NSFW or toxic content.

## Dataset Structure

### Data Instances

The dataset is formatted in JSONL, where each line is a JSON object. Below is an example:

```json
{
    "input": "Guten Tag!",
    "output": "Guten Tag! Wie kann ich Ihnen heute helfen?",
    "language": "German"
}
```

### Data Fields

- **`input` (string)**: The user-provided query or prompt.
- **`output` (string)**: The AI-generated response to the input.
- **`language` (string)**: The language used in the interaction.

## Considerations for Using the Data

### Biases

As the dataset is generated from user queries and AI responses, it may contain biases inherent in the underlying AI model or reflective of common societal biases. Additionally:

- Some entries may contain NSFW or toxic content.
- Ethical, cultural, and societal biases present in the data could propagate to models trained on it.

> [!CAUTION]
> **Caution:** It is recommended to filter this dataset before using in production applications as it may contain innapproprate data.

### Other Known Limitations

- Certain topics may be overrepresented or underrepresented based on user query patterns.
- Content diversity may not fully reflect real conversational scenarios.
- Some languages may be incorrectly labeled, please use with caution.
