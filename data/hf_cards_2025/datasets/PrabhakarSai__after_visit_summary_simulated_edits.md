# Dataset Card: AVS edits Dataset
## Dataset Summary
- The AVS edits dataset is designed to support human feedback research in for clinical summarization. It contains synthetic edit feedback generated by large language models (LLMs) to improve the factual consistency and quality of summaries. The dataset includes training, evaluation, and test splits with specific fields for modeling and evaluation tasks.

## Dataset Structure
### Train Split
- **Keys:**
  - `article`: The input clinical note or article.
  - `chosen`: The preferred summary or sentence edited to improve factual alignment.
  - `rejected`: The non-preferred summary or sentence with factual inaccuracies.
  - `hallucination_instructions`: Instructions to guide the model on resolving hallucinated or incorrect content in the `rejected` text.
### Evaluation and Test Splits
- **Keys:**
  - `text`: The input text or clinical note for summarization.
  - `summary`: The ground truth summary aligned with the input text.

## Supported Tasks
This dataset supports tasks related to:
1. **Factual Alignment in Summarization:**
   - Fine-tuning and evaluating models to align summaries with input articles.
   - Incorporating synthetic edit feedback for improved factual consistency.
2. **Preference Optimization:**
   - Training models using chosen and rejected summaries for direct preference optimization (DPO) or similar approaches.
3. **Evaluation of Summarization Models:**
   - Using the evaluation and test splits to assess models based on metrics such as ROUGE and factual accuracy.

## Dataset Creation
The dataset was generated using synthetic edit feedback produced by large language models (e.g., GPT-3.5, GPT-4). Two types of preference data were created:
1. **High→Low:** Introduced factual inaccuracies into high-quality summaries to produce rejected versions.
2. **Low→High:** Improved lower-quality summaries to produce chosen versions.

This process leverages expert instructions to guide edits, ensuring high-quality preference data for training.

## Metrics
The dataset is suitable for evaluating models using:
- **ROUGE**: Standard metric for summary quality.
- **Factual Accuracy**: Assessing the alignment between summaries and input articles.
- **ConceptRouge/SAGE**: Additional domain-specific metrics for medical summarization.
