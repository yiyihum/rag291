# tw-instruct-500k-Q-R1

<a href="https://discord.gg/fj6WbHMvfs" target="_blank">[👋歡迎加入 Discord 討論，我們正在找人一塊擴充這個對話集🎉]</a>

<!-- Provide a quick summary of the dataset. -->
**台灣常見任務對話集（Common Task-Oriented Dialogues in Taiwan）** 為台灣社會裡常見的任務對話，從 [lianghsun/tw-instruct](https://huggingface.co/datasets/lianghsun/tw-instruct) 截取出 50 萬筆的子集合版本，進行理解力(Reasoning)資料補充生成。

## Dataset Details

### Dataset Description

<!-- Provide a longer summary of what this dataset is. -->

這個資料集為合成資料集（synthetic datasets），內容由 a. **reference-based** 和 b. **reference-free** 的子資料集組合而成。生成 reference-based 資料集時，會先以我們收集用來訓練 [lianghsun/Llama-3.2-Taiwan-3B](https://huggingface.co/lianghsun/Llama-3.2-Taiwan-3B) 時的繁體中文文本作為參考文本，透過 LLM 去生成指令對話集，如果參考文本有特別領域的問法，我們將會特別設計該領域或者是適合該文本的問題；生成 reference-free 時，則是以常見的種子提示（seed prompts）作為參考，讓 LLM 去生成以 **台灣為場景** 的對話集。

上述 LLM 採用 **OpenAI GPT-4o** 或 **[Qwen/Qwen2.5-14B-Instruct](https://huggingface.co/Qwen/Qwen2.5-14B-Instruct)** ，種子提示則是以 [Self-Instruct: Aligning LM with Self Generated Instructions](https://github.com/yizhongw/self-instruct) 、[HuggingFaceH4/self-instruct-seed](https://huggingface.co/datasets/HuggingFaceH4/self-instruct-seed) 和其它 🤗 Hugging Face 上的開源種子提示。

## Dataset Creation

### Curation Rationale

<!-- Motivation for the creation of this dataset. -->
繁體中文一直缺少開源且有一定筆數的對話集，要不然就是對話集並沒有針對 **台灣社會** 去設計的對話，前述的繁中語料即使訓練完了，就仿佛是： `會講中文，但對台灣並不了解。` 在這個合成對話集，我們透過 reference-based 的設計方式，讓對話集內是含有台灣社會的文本知識，訓練後模型是能夠學習到台灣社會的常見問答。
