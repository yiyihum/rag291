# Llama-3.3-70B-Inst-awq Responses for RefAlign Safety Alignment

This dataset contains responses generated for the paper [Learning from Reference Answers: Versatile Language Model Alignment without Binary Human Preference Data](https://huggingface.co/papers/2504.09895), which introduces the `RefAlign` alignment algorithm.

**Code Repository:** [https://github.com/mzhaoshuai/RefAlign](https://github.com/mzhaoshuai/RefAlign)

This dataset specifically consists of responses generated by the [casperhansen/llama-3.3-70b-instruct-awq](https://huggingface.co/casperhansen/llama-3.3-70b-instruct-awq) model, given the prompts from the [PKU-Alignment/PKU-SafeRLHF](https://huggingface.co/datasets/PKU-Alignment/PKU-SafeRLHF) dataset.

During generation, we use three random seeds (13, 21) to generate two responses and use the model itself to choose the helpful/harmless response.

This results in the `saferlhf.json` file, available at: https://huggingface.co/datasets/mzhaoshuai/Llama-3.3-70B-Inst-awq_SafeRLHF/blob/main/saferlhf.json.
