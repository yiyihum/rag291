# ProofBench Dataset

ProofBench is a comprehensive benchmark dataset for evaluating AI models on mathematical proof generation and verification. The dataset contains competition-level mathematics problems from prestigious international competitions, along with both AI-generated and reference solutions, expert ratings, and detailed marking schemes.

## Dataset Overview

- **Total Problems**: 435
- **Competitions**: PUTNAM, IMO, USAMO, EGMO, APMO, TST
- **Years Covered**: 2022-2025
- **AI Models**: OpenAI-o3, Gemini-2.5-pro, DeepSeek-R1-0528

## Dataset Structure

Each entry in the dataset contains the following fields:

```json
{
  "problem_id": "Unique identifier for problem (e.g., 'APMO-2023-2')",
  "problem": "Problem statement in LaTeX format",
  "generator": "Name of the AI model that generated the solution",
  "model_solution": "AI-generated proof solution",
  "reference_solution": "Official/reference solution",
  "expert_rating": "Expert rating from 0-7",
  "marking_scheme": "Detailed grading rubric",
  "generation_prompt": "Prompt used to generate the solution",
  "metadata": {
    "contest": "Competition name",
    "contest_year": "Year of the competition"
  }
}
```

## Use Cases

1. **Proof Generation**: Train and evaluate models on generating mathematical proofs
2. **Proof Verification**: Develop systems to verify correctness of mathematical arguments
3. **Mathematical Reasoning**: Benchmark AI capabilities on advanced mathematical problem-solving
4. **Automated Grading**: Build systems that can grade mathematical proofs using the marking schemes
5. **Comparative Analysis**: Compare performance across different AI models on the same problems
