# Dataset Card for "nano_chat"

## Dataset Summary

**nano_chat** is a synthetic dataset consisting of **2326 short dialogues** in **simple, learner-friendly English**. It was generated using Google's `Gemini 2.5 flash` model and is designed for training **tiny conversational language models** in low-resource settings.

Each dialogue simulates a realistic conversation between two speakers (A and B), using short sentences, simple grammar, and occasional small mistakes to help models generalize better.

With ~542,000 tokens total, the dataset is ideal for:
- Pretraining small LMs from scratch (e.g., <50M parameters)
- Instruction tuning for basic dialogue understanding
- Experiments in controlled, low-complexity conversational grounding

## Generation Details

- **Model**: Gemini 2.5 flash
- **Language**: English (simple, informal)

- **Generation config**
```json
{
  "temperature": 1.1,
  "top_p": 0.95,
  "top_k": 45,
  "max_output_tokens": 4096
}
```

## Supported Tasks

- Small-scale conversational pretraining
- Instruction tuning in constrained settings
- Readability and grammar generalization tests
- Dialogue modeling for children’s or educational tool
- Text labeling

## Limitations

- Fully synthetic: Generated by a language model with no human post-editing
- Language intentionally degraded: Includes small grammar issues by design
- Limited topic variety compared to natural corpora
