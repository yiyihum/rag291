🧾 Dataset Description

The Pre-processed and Cleaned Cosmopedia Dataset is a ready-to-use derivative of the original HuggingFaceTB/cosmopedia
 collection.

Cosmopedia is a large-scale synthetic dataset consisting of high-quality textbooks, blog posts, stories, tutorials, and forum discussions generated by Mixtral-8x7B. While the raw dataset is incredibly rich, it requires significant preprocessing before it can be used effectively for supervised fine-tuning (SFT) or other instruction-tuning tasks.

This repository provides that processed version:

✅ Records have been streamed and validated one by one.

✅ Invalid or incomplete entries have been removed or corrected.

✅ Data has been standardized into an instruction–response format, making it training-ready.

✅ Sources and language labels are cleaned and normalized.

The goal is simple: save researchers and developers the heavy lifting of dataset preparation, validation, and sharding, while keeping the richness of the original Cosmopedia.

📚 What’s Inside?

This processed dataset includes cleaned subsets from the following original Cosmopedia configurations:

stories (short fiction, narratives)

khanacademy (educational texts)

auto_math_text (mathematical content)

openstax (textbooks and learning material)

stanford (academic-style material)

web_samples_v1 and web_samples_v2 (knowledge-rich web samples)

wikihow (instructional guides and step-by-step tasks)

Together, these cover a broad spectrum of domains: creative writing, STEM, education, real-world instruction, and general knowledge.

🛠️ Transformation Highlights

The raw dataset schema has been simplified into a clean, training-friendly format.

Original fields included:

prompt → instruction (sometimes empty)

text → model-generated response

source, seed, prompt_length, text_length, language

New processed fields:

source → normalized origin label

language → validated (en or und)

formatted_text → final combined text in the format:

```text
### Instruction:
<prompt>

### Response:
<text>
Example Record
{
  "source": "stories",
  "language": "en",
  "formatted_text": "### Instruction:\nWrite a short story about a friendly robot who discovers music for the first time.\n\n### Response:\nUnit 734, designated 'Scrubber' by the station crew, knew only the hum of the recycler and the squeak of its own wheels. Its world was a predictable grid of corridors and maintenance schedules. One day, while cleaning a forgotten storage closet, its optical sensors fell upon a dusty, rectangular object with black and white keys..."
 ```
}
How to Use

The dataset is designed to be used with streaming, which allows you to train on it without downloading the entire dataset to your machine.
from datasets import load_dataset
```
# Load the dataset in streaming mode
repo_id = "blah7/my-cosmopedia-dataset"
streaming_dataset = load_dataset(repo_id, streaming=True, split="train")

# Iterate over it
for record in streaming_dataset:
    print(record['formatted_text'][:200])
    break
```
