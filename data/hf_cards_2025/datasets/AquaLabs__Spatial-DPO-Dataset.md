# Spatial-DPO-Dataset

## Overview

This dataset was created to train language models for 3D-to-Speech conversion, specifically for the EchoLLaMA project. It contains 2,000 samples of prompts derived from 3D image analyses paired with two types of responses: high-quality responses from DeepSeek-V3-0324 (chosen) and baseline responses from LLaMA-3.2-1B-Instruct (rejected). This structure enables Direct Preference Optimization (DPO) for fine-tuning language models to generate detailed and contextually accurate descriptions of 3D scenes.

## Dataset Structure

Each sample in the dataset includes:
- **Prompt**: A structured input combining:
  - An image description generated by the Moondream model
  - A grid-based object detection matrix from DETR augmented data
- **Chosen Response**: High-quality description generated by DeepSeek-V3-0324
- **Rejected Response**: Baseline description generated by LLaMA-3.2-1B-Instruct (pre-fine-tuning)

### Example Prompt Format

```
Image Description: [Moondream-generated description]
This grid-based object detection matrix represents detected objects in different regions of the image. [Object Detection Matrix]
Describe this place in detail.
```

### Object Detection Matrix Format

The object detection matrix is structured as a 2×3 grid containing object information with:
- Object name
- Detection probability (threshold: 0.9)

## Dataset Creation

1. **Image Selection**: 2,000 images from the COCO 2017 training set depicting various 3D scenes
2. **Image Processing**:
   - DETR for object detection (2D spatial locations)
   - Moondream for natural language description
3. **Prompt Construction**: Combined image description and object detection matrix
4. **Response Generation**:
   - DeepSeek-V3-0324 for chosen responses
   - LLaMA-3.2-1B-Instruct for rejected responses
   - Parameters: max_tokens=1024, temperature=0.7, top_p=0.95

## Use Cases

- Fine-tuning language models via DPO for 3D scene description
- Training models to understand spatial relationships in images
- Developing multimodal AI systems that connect visual data with natural language
- Building 3D-to-Speech conversion systems
